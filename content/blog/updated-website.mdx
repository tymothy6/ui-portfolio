## New website tech stack

👋🏼 Hey there, hope you had an amazing summer! 😎

I'm excited to share that my new website is up and running. It's built with Radix UI and shadcn/ui React components, TypeScript, and the Next.js framework. Check out the [Style Guide](https://tim-ng.me/style) and [Licenses](https://tim-ng.me/licenses) pages for more technical details. I built the website with a mobile-first approach made effortless with responsive TailwindCSS classes. Based on some existing code I've written, my content is fetched from Contentful, but I've been looking into Sanity as a replacement headless CMS.

It was my first time building a React app with CSS-in-JS rather than CSS modules and I enjoyed having concise and semantic references in a single file. With that said, I know there's a strong advantage of documenting your design system separately from its implementation especially for a more complex project. I can definitely see downsides of working with the Tailwind framework but I think there's a great balance of structure and freedom (arbitrary classes? no problem). Stay tuned for new projects, updates to the landing page, site-wide animations, and incremental UX updates.

Please poke around, share your thoughts, and let me know if you encounter any 🐛.
